## AstraBridge 0.3.0 release candidate 2

### Jumping and falling

- Added `jump` with directional movement, optional running and automatic stopping on landing. A short time budget allows the agent to inspect and adjust an unfinished jump.
- Added `air-move` for steering during both jumps and ordinary falls, plus `wait-until landed`.
- Observations now explicitly report ground support, ascending/descending state and measured vertical speed, including in compact responses.
- Jump results report observed takeoff, landing, displacement, peak height and damage taken. Sending Jump without taking off is no longer presented as a successful jump.
- Updated the gameplay skill with directional controls, momentum, midair pauses and result interpretation. Normal OpenMW physics and Acrobatics remain unchanged.

### Downloads and update

- **Linux:** download the x86_64 AppImage and make it executable.
- **Windows:** extract the x86_64 portable ZIP and run `astrabridge.exe`. Keep the extracted files together.
- Existing container installations: open the new application and explicitly update the runtime in Setup. Managed profiles, saves, Atlas and knowledge are preserved.
- The matching runtime is `ghcr.io/incident201/astrabridge-runtime:v0.3.0-rc2`; its exact OCI digest is embedded in the application and included in `release.json`.

Supply your own Morrowind installation. See the [system requirements](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc2/docs/system-requirements.md) and [installation instructions](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc2/README.md).

`SHA256SUMS` covers the application packages, release metadata and corresponding source archive. This remains a pre-release; stable 0.2.2 is unchanged.
