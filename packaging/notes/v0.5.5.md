## Changes

- Fixed MiMo tool calling in AstraBridge Runner by switching MiMo to its Chat Completions API. Multi-turn gameplay no longer relies on the Responses compatibility endpoint that returned XML-like text instead of executable tool calls.
- Preserved complete reasoning, text history, screenshots, diagnostics, session resume, checkpoint compaction and token/cache statistics. Other providers keep their existing transports.
- Added regression coverage for streamed tool calls, interrupted responses, batch rejection and recovery, retries, and history replay.

Includes AstraBridge Runner 0.1.7. Launch commands and API-key configuration are unchanged.
