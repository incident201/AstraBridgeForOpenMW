## AstraBridge 0.3.0 release candidate 1

This pre-release introduces the container runtime and the unified Desktop/CLI application.

### What's new

- A versioned Linux runtime image containing modified OpenMW, AstraBridge, a private Weston/XWayland display, Python and FFmpeg.
- Linux support through rootless Podman and Windows support through WSL Containers.
- Desktop with live video/audio, fullscreen, manual keyboard/mouse control and recording replay. Rewinding or pausing the viewer does not interrupt gameplay or recording.
- Independent profiles for saves, Atlas, knowledge, notes and session history, with profile duplication and explicit switching while the game is stopped.
- An interactive Atlas with a large map, automatic route fitting, zoom, pan, point selection and readable location transitions.
- Independent rendering and encoding GPU selection, including hybrid AMD/Intel + NVIDIA configurations. Hardware encoding is verified with a real encode probe, with CPU fallback.
- Host recording folders, optional game-data copying, and explicit runtime updates with data preservation and recovery.

### Downloads and setup

- **Linux:** download the x86_64 AppImage and make it executable.
- **Windows:** extract the x86_64 portable ZIP and run `astrabridge.exe`. Keep the extracted files together; application dependencies are included.
- Supply your own Morrowind installation. Game files are not included.
- The application installs its matching runtime from `ghcr.io/incident201/astrabridge-runtime:v0.3.0-rc1`; the exact OCI digest is embedded in the application and included in `release.json`.

Read the [system requirements](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc1/docs/system-requirements.md) for Podman/WSL Containers and GPU prerequisites, and the [installation instructions](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc1/README.md).

This is a new installation format. There is no automatic migration of a legacy 0.2.x portable installation; keep that installation and its saves intact when setting up the container version. The stable 0.2.2 release remains available.

`SHA256SUMS` covers the application packages, release metadata and corresponding source archive.
