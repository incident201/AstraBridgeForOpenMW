## Changes

- Added Xiaomi MiMo support to AstraBridge Runner through the Responses API, including MiMo V2.6 Pro. Use `--provider mimo` with `MIMO_API_KEY`.
- MiMo uses the existing tool execution, screenshot handling, session resume, checkpoint compaction and token/cache statistics. Checkpoints use JSON mode with local schema validation.
- Updated the runner guide with MiMo authentication and launch instructions. Use `--reasoning high` for thinking or `--reasoning none` to disable it; MiMo currently treats all enabled reasoning levels alike.

Includes AstraBridge Runner 0.1.6. Existing runner sessions and game profiles remain compatible.
