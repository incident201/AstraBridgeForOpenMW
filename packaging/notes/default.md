AstraBridge Desktop and CLI with a matching container runtime.

- Linux x86_64 AppImage and Windows x86_64 portable ZIP.
- Versioned runtime image in GHCR; its immutable digest is embedded in the application and included in `release.json`.
- Supply your own game data and install the host container/GPU prerequisites described in the documentation.
- `SHA256SUMS` covers the packages, release metadata and corresponding source archive.
