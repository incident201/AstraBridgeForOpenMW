## Changes

- Smoother automatic movement and obstacle avoidance, with fewer stop-and-turn pauses. Ground navigation keeps its collision and floor-support checks, and can use known travelled routes when the normal path crosses an obstacle.
- Smaller gameplay responses: unchanged equipment, effects and settings are no longer repeated on every step. Action results use a single outcome summary while preserving actual movement, interruptions and obstacle diagnostics. Full results remain available on request.
- More concise UI, character, recording and Atlas responses.
- Updated gameplay skill with corrected command descriptions and less implementation detail. Fixed native-tool skill exports losing comment text or checkpoint arguments and confusing field names with tool names.

## Updating

Re-export the gameplay skill after updating. Custom integrations should read `result.summary` for the effective action outcome; the default compact response no longer repeats it in `feedback`. Use `--full`, `details` or `action-result` when additional information is needed.
