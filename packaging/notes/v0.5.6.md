## Changes

- Fixed legacy MWScript events continuing during AstraBridge pauses. Scripted gates, moving objects and their timers now stop while the agent is thinking. Scripted UI remains responsive without advancing time-based movement.
- Added `astrabridge-runner resume SESSION_PATH --compact` to create a checkpoint before continuing, even below the automatic compaction threshold or when automatic compaction is disabled. Full session logs are preserved, and a failed compaction leaves the previous context intact.

Includes AstraBridge Runner 0.1.8 and an updated OpenMW engine. Existing game profiles and saves remain compatible.
