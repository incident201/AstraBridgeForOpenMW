## AstraBridge 0.3.0 release candidate 4

### Working-task memory

- Added `knowledge checkpoint` and `knowledge brief` for an agent-authored current goal, next step, evidence links, remembered objects/places and failed approaches.
- Checkpoints are stored persistently in the current playthrough's knowledge database. Writes replace the current checkpoint atomically; temporary gameplay handles are rejected in reference fields.
- Agent connection and observations include a small working-memory indicator. The complete checkpoint is returned only when requested.
- Loading a save marks a checkpoint from the previous continuation as requiring revalidation. Reading it does not clear that flag or change existing note statuses. Profiles retain independent storage, including after explicit duplication.

### Gameplay skill

- Reduced the main skill from approximately 2,700 to 1,200 words and split detailed session, onboarding, UI, memory, sequence and recording instructions into focused references.
- Preserved mandatory gameplay-access boundaries and the skill's identity.
- Added examples for predictable action sequences and guidance on choosing structured text or screenshots, including the shared final image of a completed scan.

### Downloads and update

- **Linux:** download the x86_64 AppImage and make it executable.
- **Windows:** extract the x86_64 portable ZIP and run `astrabridge.exe`. Keep the extracted files together.
- Existing container installations: open the new application and explicitly update the runtime in Setup. Managed profiles, saves, Atlas and knowledge are preserved.
- **Export the gameplay skill again after updating**, and give the new export to your agent to use the new commands and instructions.
- The matching runtime is `ghcr.io/incident201/astrabridge-runtime:v0.3.0-rc4`; its exact OCI digest is embedded in the application and included in `release.json`.

Supply your own Morrowind installation. See the [system requirements](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc4/docs/system-requirements.md) and [installation instructions](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc4/README.md).

`SHA256SUMS` covers the application packages, release metadata and corresponding source archive. This is a pre-release.
