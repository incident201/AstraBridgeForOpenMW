## Changes

- Migrated DeepSeek to the Responses API, sharing streaming, tool calls and image handling with the OpenAI and Grok adapters.
- Added native JSON Schema output for checkpoints across OpenAI, DeepSeek, Grok and Gemini. OpenAI commentary is preserved in logs without interfering with checkpoint parsing.
- Added per-request and cumulative token/cache statistics, with separate checkpoint usage and totals preserved across session resume. Inspect saved sessions with `astrabridge-runner logs stats SESSION`, optionally with `--json`.

Includes AstraBridge Runner 0.1.4.

**DeepSeek session compatibility:** Conversations created by the previous Chat Completions adapter cannot be resumed with the new runner. Start a new runner session in the same game profile to continue playing. Existing game saves and archived logs are preserved.
