# AstraBridge 0.3.2

- Fixed CLI registration and repair in Linux AppImages: the application's own internal command is no longer mistaken for a conflicting host installation.
- Gameplay skill export now works without registering the CLI. It uses the permanent command when available, or the current application path and configuration otherwise.
- Clarified CLI setup controls and allowed an existing registration to be removed while a runtime update is required.

If CLI setup failed in 0.3.1, open **Setup → Storage and skill → Enable CLI command** after updating. Existing registered commands and skill exports remain usable.
