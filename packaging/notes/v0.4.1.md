# AstraBridge 0.4.1

- Keep engine and lifecycle diagnostic logs bounded, and continue draining engine
  output if a log cannot be written. Late command replies no longer accumulate.
- Keep the daemon responsive during text input and report input failures without
  disconnecting the viewer. Session history tolerates interrupted log entries.
- Recover abandoned installation locks, terminate timed-out runtime downloads
  and their child processes, preserve UTF-8 output, and validate Windows game paths.
- Compact old action-result payloads while preserving protection against repeated
  commands. Runner API logs share archived screenshots; an explicit cleanup
  command can remove old inactive runner sessions. API retries respect Retry-After.
- Pin GitHub Actions to commit SHA values and add Python correctness checks to CI.
