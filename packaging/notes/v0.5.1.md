## Changes

- Added Google Gemini API support to AstraBridge Runner, including Gemini 3.8 Flash with low, medium or high reasoning effort.
- Gemini uses native tools, game screenshots, persistent conversation history, checkpoint compaction and session resume. Thought signatures and complete tool results are preserved.
- Adapted conditional tool schemas for Google's API validation while retaining AstraBridge's original argument checks.
- Added compact, reconstructable logging for Gemini images and protected API-key handling.

Includes AstraBridge Runner 0.1.3. Set `GEMINI_API_KEY` and select `--provider gemini`; see the runner documentation for setup and examples.
