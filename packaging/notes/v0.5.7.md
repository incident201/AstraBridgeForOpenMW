## Changes

- Made Game API responses relevant to the requested operation. UI choices and closing tutorial windows no longer append unrelated surroundings, passages or character statistics. Movement retains navigation and obstruction information; detailed state remains available through explicit queries and `--full`.
- Reduced repeated scene metadata, motion fields, notifications and recording diagnostics. State comparison tracks what was actually delivered, so omitted information remains available when subsequently requested.
- Improved dialogue replies to show newly added answers instead of repeating accumulated conversation history. Explicit UI queries provide current controls and recent dialogue; complete text remains accessible through `details ui`.
- Fixed `audio_ring_overrun` when video pacing or encoder backpressure delayed audio reads. PCM continues draining during video queue waits, and audio beyond the recording's acknowledged end cannot trigger a false overrun. Recording quality and the engine-owned timeline are preserved.
- Updated gameplay skill instructions, API/media documentation and model observations. Added recording backpressure regression coverage, including an encoded audio/video test in release CI.

Re-export the gameplay skill after updating to get the revised response instructions. Existing profiles and saves remain compatible. Includes AstraBridge Runner 0.1.8; no separate runner update is required.
