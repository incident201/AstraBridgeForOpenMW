## AstraBridge 0.3.0 release candidate 9

### Session lifecycle

- Added a visible **Stop session** button, including in fullscreen. It disconnects the agent, finishes recording, closes live view and stops the game and container. It does not create a game save.
- Fixed slow shutdown caused by event WebSockets closing too late and the live-view encoder waiting on an open input pipe. Recording still drains and finalizes normally.
- Agents now receive `user_requested_stop`, `retryable: false` and available interrupted-action diagnostics when the user ends the session. The stop reason remains available after container shutdown. A new explicit host start is required before the agent can reconnect.
- All startup logos, introduction videos, credits, scripted cutscenes and animated menu backgrounds are skipped automatically. Game files remain unchanged.

### Desktop and recordings

- Removed the redundant OPENMW RUNTIME subtitle and duplicate sidebar profile/runtime indicators. The AstraBridge logo remains, with one primary game/session status in the header.
- Compacted Setup and removed stretched vertical gaps.
- Commentary displays complete messages with line wrapping. Long messages scroll within the transparent overlay without shrinking the game view. Live, replay and fullscreen share the layout.
- Enlarged Wall/Game clocks and darkened their background for readability.
- Added **Delete recording** with confirmation. It removes the selected video and its timeline, metadata and recording logs directly from the host folder, including while the container is stopped.

### Downloads and update

- **Linux:** download the x86_64 AppImage and make it executable.
- **Windows:** extract the portable ZIP and run `astrabridge.exe`.
- Open the new application and update the runtime in Setup. A normal update preserves managed data.
- Export the updated gameplay skill so the agent receives the session-termination instructions.
- Runtime: `ghcr.io/incident201/astrabridge-runtime:v0.3.0-rc9`. Its exact digest is embedded in Desktop and recorded in `release.json`.

Supply your own Morrowind installation. See the [system requirements](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc9/docs/system-requirements.md). `SHA256SUMS` covers the application packages, release metadata and source archive. This is a pre-release.
