## AstraBridge 0.3.0

### Main changes since 0.2.2

- **Desktop application and Windows support.** Linux AppImage and Windows portable ZIP, with a graphical interface and CLI in the same application.
- **Containerized runtime.** Modified OpenMW, the private game display, Python and FFmpeg are packaged together. Linux uses Podman; Windows uses WSL Containers. Rendering and recording GPUs can be selected explicitly, including on hybrid systems.
- **Live viewer and manual control.** Watch the game in fullscreen, take keyboard/mouse control when the agent is disconnected, or pause and rewind recorded footage while gameplay and recording continue in the background.
- **Independent playthrough profiles.** Create, duplicate, rename and switch profiles, each with separate saves, settings, Atlas and agent knowledge. The interactive Atlas provides a zoomable map of explored routes and visited places.
- **Recording management and spectator overlays.** Recordings are saved to a host folder and can be played, exported or deleted without starting the game. Optional agent commentary, action history and clocks stay synchronized when replaying or seeking through a recording.
- **Improved agent controls and memory.** Directional jumps and mid-air steering, clearer movement and navigation results, and persistent task checkpoints for resuming after context loss. The gameplay skill is shorter, with detailed instructions loaded as needed.
- **Installation and lifecycle management.** Guided setup, dependency checks, update recovery, reset/uninstall controls and a single full-session Stop action. Downloads show progress, and unchanged container layers are reused for smaller subsequent updates.
- **Updated gameplay defaults.** New profiles use neutral difficulty (`0`), and videos are skipped automatically.

### Upgrading

The 0.2.x portable installation is not migrated automatically. Set up 0.3.0 as a new installation and keep your existing saves and runtime data. Existing 0.3.0 RC installations can use **Update runtime** in Setup.

Supply your own Morrowind installation. See the [installation guide](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0/README.md) and [system requirements](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0/docs/system-requirements.md).
