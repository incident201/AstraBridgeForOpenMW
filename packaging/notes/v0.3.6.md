# AstraBridge 0.3.6

- Added the shared `astrabridge-runner` for OpenAI GPT models through **Sign in with ChatGPT** and the Responses API, and for DeepSeek through its API.
- Added model and reasoning selection, a configurable recent screenshot window, structured checkpoint compaction, and session resume. Complete requests, responses, tool results, screenshots, usage, and checkpoints remain in the session logs.
- Game tools and argument schemas come from AstraBridge's existing catalog. The runner executes tools sequentially, preserves full diagnostics, and provides no shell or Python scripting tools to the model.
- Updated model results with the Sol and Luna custom-harness comparisons, a current-status table, and recommended harnesses.

The installable `astrabridge_runner` Python wheel replaces the experimental DeepSeek-only runner. Start a new runner session; the experimental runner's session format is not migrated.

See [AstraBridge Runner setup and usage](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.6/docs/agent-runner.md).
