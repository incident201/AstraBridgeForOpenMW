## AstraBridge 0.3.0 release candidate 6

### Live viewer and spectator timeline

- The viewer connects automatically after starting the game and stays connected when switching tabs. An explicit disconnect keeps it off until you reconnect.
- Added optional, lightweight commentary, action-history and session-clock overlays. They sit over the game image without reducing its size, and remain visible in fullscreen when the controls are hidden.
- Added the model-independent `astrabridge game comment "TEXT"` command. It publishes a spectator message without pausing gameplay or interrupting an active action. External agent chat is not captured automatically.
- Action history retains recent commands and their outcomes, with the active action highlighted. Wall time counts agent-connected time; game time follows engine simulation and stops during pauses.
- Comments, actions and clock samples are saved with recording timestamps in `.events.jsonl` sidecars. Seeking restores the history at the selected video position; pausing freezes it, and returning to Live restores current events.
- Saved recordings can also display their synchronized overlays and expand to fullscreen together with them. Existing recordings without event sidecars remain playable without historical overlays.
- Moved audio and manual-control buttons above the game, stabilized the FPS indicator, clarified gameplay/pause status and removed the redundant GPU footer.

### Recordings, profiles and setup

- Recordings can be browsed, played, sought and exported directly from their host folder with the container stopped or removed. Fixed concurrent daemon-start requests causing an improper-container-state error.
- New recording filenames include the profile name. The recording browser supports all profiles or the selected profile, and can export the event timeline separately.
- Exported gameplay skills no longer bind an agent to one profile. Connecting uses the profile currently selected in Desktop; switching profiles does not require another skill export.
- The selected profile is shown as a noninteractive label and clearly marked in the profile list.
- Replaced technical text-encoding labels with **Game language**. The standard game data folder is detected automatically; custom subfolders remain available under Advanced.
- New installations default to neutral difficulty (`0`). Best attack remains enabled. Existing configured gameplay preferences are preserved.
- Added an application icon, removed the standard menu bar and corrected spacing in System requirements.
- Updated the gameplay skill and developer documentation.

### Downloads and update

- **Linux:** download the x86_64 AppImage and make it executable.
- **Windows:** extract the x86_64 portable ZIP and run `astrabridge.exe`. Keep the extracted files together.
- Existing installations: open the new application and explicitly update the runtime in Setup. Managed profiles, saves, Atlas and knowledge are preserved.
- **Export the updated gameplay skill once after this update.** The same export then works across profile changes.
- The matching runtime is `ghcr.io/incident201/astrabridge-runtime:v0.3.0-rc6`; its exact OCI digest is embedded in the application and included in `release.json`.

Supply your own Morrowind installation. See the [system requirements](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc6/docs/system-requirements.md) and [installation instructions](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc6/README.md).
