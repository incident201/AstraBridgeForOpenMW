## AstraBridge 0.3.0 release candidate 7

### Installation recovery and uninstall

- Added **Reset setup only** to clear stale, interrupted or malformed installation configuration and choose game files, managed storage and recordings again.
- Added **Remove installation and data**. It stops the runtime, removes its container, profiles, saves, Atlas, notes, snapshots and imported game copy, and clears configuration after successful cleanup.
- Original host game files and recordings are retained. On Linux, UID-mapped storage files are removed through Podman without sudo. An otherwise unused managed store is cleaned without resetting rootless infrastructure shared with other stores.
- Missing containers and volumes are treated as already removed. Partial uninstall can be retried from Setup.
- Missing managed data is detected before update or recovery attempts. The application no longer tries to back up a deleted store or reports that deleted data is still preserved.
- Update and recovery ensure the exact old runtime image is available before stopping or replacing anything.

### Steam installs and game startup

- Fixed importing the selected files in `Morrowind.ini` as if their entry numbers were OpenMW's load order. Import now considers timestamps and TES3 header master dependencies, including Morrowind → Tribunal → Bloodmoon.
- Existing invalid dependency ordering is repaired without enabling additional files or re-sorting an already valid custom order. Missing masters and dependency cycles produce clear errors.
- Fixed startup logos and in-game movies hanging with engine-owned loopback audio. Movie playback now advances the audio/video timeline in its own rendering loop and avoids blocking video decoding on synchronous audio refill.
- Added an explicit **Starting game** state. A living process is no longer reported as a ready game before the bridge handshake completes.
- Stop can cancel startup without waiting for an unavailable gameplay interface. Lifecycle shutdown timeouts are honored, and startup errors remain visible in Desktop.

### Downloads and update

- **Linux:** download the x86_64 AppImage and make it executable.
- **Windows:** extract the portable ZIP and run `astrabridge.exe`.
- Open the new application and update the runtime in Setup. Existing managed data is preserved by a normal update.
- If managed storage was already deleted, use **Reset setup only** instead of Update/Recover, then install again.
- This release includes the viewer, synchronized overlays and profile-independent skill changes from rc6. Export the current gameplay skill after updating the application; profile changes do not require another export.
- Runtime: `ghcr.io/incident201/astrabridge-runtime:v0.3.0-rc7`. The exact OCI digest is embedded in Desktop and recorded in `release.json`.

Supply your own Morrowind installation. See the [system requirements](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc7/docs/system-requirements.md). `SHA256SUMS` covers the application packages, release metadata and source archive. This is a pre-release.
