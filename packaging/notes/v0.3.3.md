# AstraBridge 0.3.3

- Added large in-game local and world maps with dedicated commands for panning, zooming, centering and returning to the regular game view. Agents receive native-resolution images, normally 1920×1080.
- Added searchable, paginated labels and tooltip notes for visible map markers. The game's exploration fog and normal UI access restrictions remain in effect.
- Map interactions appear in the live viewer and recordings. Closing the large map restores the original window size; the existing windowed map command remains available.
- Updated the gameplay skill with the new map commands and viewing workflow.

After updating the runtime, export the gameplay skill again to give the agent the new instructions. Existing profiles, saves, Atlas data and recordings are preserved.
