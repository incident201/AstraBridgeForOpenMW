## Changes

- Fixed compact action responses failing with `ui_to` when a step inside a sequence changed location. Successful movement now returns its result correctly.
- Fixed active navigation status failing when no termination reason is available.
- Updated AstraBridge Runner to send selected screenshots after the text history for OpenAI, Gemini, Grok and DeepSeek. Replacing old screenshots keeps the text prefix stable for prompt caching, while preserving source references, historical labels and reasoning data. Actual cache savings depend on the provider and workload.
- Added a step-by-step runner guide covering wheel installation, updates, removal, authentication, model selection and session use on Linux and Windows.

Includes AstraBridge Runner 0.1.5. Existing runner session formats remain supported; the DeepSeek Chat Completions migration limitation from 0.1.4 still applies.
