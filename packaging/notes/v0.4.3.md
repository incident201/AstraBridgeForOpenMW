## Changes

- Import OpenMW `.omwsave` files into a playthrough profile from **Profiles → Import save…** or `astrabridge import-save`. Imports validate the file, preserve existing saves, and leave the profile's Atlas and notes unchanged.
- Fixed viewer cancellation when the game stops during a pending connection, preventing the interface from becoming stuck.
- Fixed a race in runtime command timeout cleanup so it waits for child processes to exit after forced termination.
