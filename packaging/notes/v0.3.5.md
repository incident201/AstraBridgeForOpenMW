# AstraBridge 0.3.5

- Added `astrabridge agent tools --json`: a native tool catalog with descriptions, JSON argument schemas, and invocation metadata generated from AstraBridge's existing command definitions.
- Added `astrabridge skill export DIRECTORY --interface tools`, presenting the gameplay rules and references for agents using native tools.
- Added an optional direct API runner for DeepSeek 4.1 Flash with max reasoning effort. It executes AstraBridge tools sequentially, preserves full text history and diagnostics, sends only the latest selected image, and archives screenshots and complete session logs. The model has no shell or Python scripting access.
- Included the runner as an installable Python wheel alongside the Desktop release assets.
- Updated the model results documentation with the direct API tests and their remaining navigation limitations.
