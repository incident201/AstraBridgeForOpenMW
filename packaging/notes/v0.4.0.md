# AstraBridge 0.4.0

- Improved navigation with the player's actual collision body, floor support and normal step limits. Short physical routes can now follow curved bridges, stairs and corridors where the native navigation mesh is incomplete.
- Added checked obstacle detours and better steering around short waypoints, including on recorded routes.
- Fixed long Atlas journeys repeatedly returning toward their departure between route segments. Connected travelled routes no longer have an arbitrary total distance limit.
- Visible objects and walking points use OpenMW's configured view distance instead of separate short selection limits.
- Fixed direct movement incorrectly reporting stalled progress while climbing or descending.
- Removed the CLI transport's independent five-minute timeout for long game actions. Action budgets, cancellation and runtime watchdogs remain in effect.
