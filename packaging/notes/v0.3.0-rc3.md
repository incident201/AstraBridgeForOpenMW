## AstraBridge 0.3.0 release candidate 3

### Host requirements and startup diagnostics

- Desktop now checks host prerequisites automatically when it opens. **Setup → System requirements** lists missing components and configuration problems together, with remedies and a **Check again** action.
- Linux checks cover Podman 5+, crun, rootless UID/GID mappings, user namespaces, networking helpers and GPU device permissions. Managed-storage checks also validate Podman's configured monitor and network backend.
- Intel and AMD render devices are checked independently of NVIDIA requirements. NVIDIA configurations additionally require a working host driver, NVIDIA Container Toolkit and registered CDI devices, including on hybrid systems that expose NVIDIA to the runtime.
- Install, start, restart and update validate prerequisites before downloading images or changing the runtime. CLI failures include a structured requirements report.
- The Linux AppImage launcher reports missing or incompatible system libraries before starting Electron, with a desktop dialog when KDialog or Zenity is available.
- Expanded installation documentation with host/container dependency separation, Intel/AMD/NVIDIA requirements, package guidance and the Podman version requirement. Hardware OpenGL and encoder probes remain the final checks inside the runtime.

### Downloads and update

- **Linux:** download the x86_64 AppImage and make it executable.
- **Windows:** extract the x86_64 portable ZIP and run `astrabridge.exe`. Keep the extracted files together.
- Existing container installations: open the new application and explicitly update the runtime in Setup. Managed profiles, saves, Atlas and knowledge are preserved.
- The matching runtime is `ghcr.io/incident201/astrabridge-runtime:v0.3.0-rc3`; its exact OCI digest is embedded in the application and included in `release.json`.

Supply your own Morrowind installation. See the [system requirements](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc3/docs/system-requirements.md) and [installation instructions](https://github.com/incident201/AstraBridgeForOpenMW/blob/v0.3.0-rc3/README.md).

`SHA256SUMS` covers the application packages, release metadata and corresponding source archive. This is a pre-release.
